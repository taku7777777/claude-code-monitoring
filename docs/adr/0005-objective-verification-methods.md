# ADR 0005: 客観的な効果検証手法を準実験（ITSA + 管理図 + CUSUM/PELT）に限定する

- ステータス: 採用
- 日付: 2026-07

## Context

コスト最適化施策（[ADR 0003](0003-outcome-signal-and-intervention-marker.md) の
`intervention_marker`）が本当に効いたかを**客観的に**検証したい。しかし本ツールの想定利用者は
**個人ローカル環境の開発者本人ひとり**（requirements.md 1 章、マルチユーザー非対応）である。

この制約が検証手法の選択を強く縛る。

- **A/B テスト（ランダム化比較）は不能**: 単一ユーザー・単一時系列では、同時に「施策あり群」と
  「施策なし群」を並走させられない。無作為割付ができない。
- **DiD（差分の差分）も対照群が要る**: 比較対象となる別ユーザー・別プロジェクト群が存在しない。
- 一方で、施策の前後で 1 本の時系列（日次コスト、日次コスト/1M実効トークン）は連続的に得られる。
  これは中断時系列（interrupted time series）の形をしている。

過剰な統計基盤（重量級ベイズ推定、p 値追跡、即時アラート）を組むこともできるが、個人ローカル
利用ではオーバーエンジニアリングになり、運用負荷に見合わない（requirements.md 3.8 スコープ外・
12.7 の「個人ローカルでは目視ガードで十分」の方針とも整合）。

## Decision

**単一ユーザー・単一時系列で成立する準実験（quasi-experiment）に検証手法を限定する。**
具体的には以下を採用する。

- **ITSA（Interrupted Time Series Analysis, 中断時系列分析）**: 施策マーカーの時刻を「中断点」
  として、前後でコスト系列の水準・傾きがどう変化したかを見る。Cost Optimization ダッシュボードで
  施策マーカーを縦線として全パネルに重畳し、目視で before/after を照合する。
- **I-MR 管理図（Individuals + Moving Range）**: 日次の単位コスト（コスト/1M実効トークン）を
  個別値管理図として扱い、管理限界 X̄±2.66·MR̄ を外れた点＝特殊原因として検出する。
  `analysis/cost-optimization-analyzer.py` の **[f] 施策効果検証** が施策マーカーごとに
  before 区間から管理限界を算出し、after 点の限界外判定＋水準シフト率で効果を確定する。
  ダッシュボードの「管理図近似」パネルは同じ系列の目視用（限界線は analyzer 側で算出）。
- **CUSUM / PELT（変化点検出）**: `analysis/cost-optimization-analyzer.py` が日次コスト系列に
  対し CUSUM（内蔵）で変化点を検出し、`ruptures` があれば PELT も併用する。施策と無関係な
  水準シフトも拾えるため、ITSA の目視を裏づける。

**明示的に採らないもの:** A/B テスト、DiD、重量級ベイズ推定、p 値追跡、即時アラート基盤。
単一ユーザーで成立しない、または個人ローカル利用に対して過剰と判断する。

## Consequences

**利点（トレードオフの表）**

- 単一ユーザー・単一時系列という制約下で**実際に成立する**手法だけを使うため、絵に描いた餅に
  ならない。施策マーカー（ADR 0003）と自然に噛み合う。
- 管理図・CUSUM・PELT はいずれも軽量で、ローカルで完結する。`ruptures` は任意依存にして
  無くても CUSUM で動く（分析スクリプトは Loki 不在でも import 時にエラーにしない設計）。
- 「目視ガード + 準実験」という現実的な粒度に収め、運用負荷を抑える（requirements.md 12.7 と整合）。

**代償・限界**

- 準実験は**因果を厳密には証明できない**。ITSA は施策と同時に起きた交絡（別の作業内容変化、
  価格改定、季節性）を排除できない。変化点が施策由来かは利用者の解釈に委ねられる。
- 単一時系列ゆえサンプルが少なく、短期間では変化点検出の検出力が低い。十分な観測期間
  （既定 7 日〜）が要る。
- 統計的有意性の定量評価（信頼区間・p 値）を意図的に持たないため、「効いた/効かない」の
  最終判断は人間の目視・ドメイン知識に依存する。これは個人ローカル利用では許容できる代償と判断。
