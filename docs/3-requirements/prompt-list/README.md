# プロンプト一覧ページ要件

## 背景 — なぜこのページがあるのか

「この時間帯、何の依頼が走っていたか」に答える時間窓ドリルダウン。
Today のバーン推移でスパイクのバーをクリックすると、**その5分窓が from/to として
引き継がれて**このページに遷移する（Today 自体の時間範囲は変えない — 常時ページの
レンジ固定規律を守るための分離）。

## 設計思想

- **一次イベント集計 × 実コスト整合**: `api_request`（CONTRACT §3.1）を `prompt_id` で
  集計し、`user_prompt` から本文を結合。コストは `cost_recalc` 優先の合計で
  **セッション/ワークスペースの総コストと一致**する（旧 `prompt_summary` は
  コストを過小計上するため使わない）。開始/終了は API 呼び出しの `observed_timestamp`
  min/max、**実行時間** = その差分
- 窓はリンクの `var-wfrom / var-wto`（ms）で渡り、**窓内に入った API 呼び出しだけ**を
  集計する（未指定＝全量）。ページの時間レンジ（既定 now-7d）は検索対象範囲で、
  窓そのものではない
- API 呼び出しが1件も無い依頼（即中断等・コスト0）は載らない
