# 一覧

データ源は `prompt_summary`（[CONTRACT §3.4](../../CONTRACT.md) — テイラーが
30秒ごとに last-wins 追記する prompt 単位サマリ）。窓は Today のバークリックから
`var-wfrom / var-wto`（ms）で渡り、ページの時間レンジは「検索対象範囲」
（窓終端の48h前〜窓終端）であって窓そのものではない。

## 1. 窓開始

### 表示
- 渡された窓の開始時刻（wfrom）。直接開いた場合は「(未指定)」

### 活用
- どの5分窓を見ているかの確認（時間ピッカーは検索範囲を示すため、窓はここで読む）

## 2. 窓終了

### 表示
- 渡された窓の終了時刻（wto）

### 活用
- 同上

## 3. プロンプト一覧（窓に実行が重なるもの・全量）

### 表示
- 窓に実行期間が重なるプロンプト（`end_ms >= wfrom` ∧ `start_ms <= wto`）を、
  **真の全体期間・総コスト**で一覧（コスト降順）
- 開始 = 入力（user_prompt）時刻 / 終了 = 最後の API 呼び出し。窓で切られない全量
- コスト・実効tok・取り込み比も prompt の総量（取り込み比は分子分母を
  summary から受けて表示時に除算 — 単調性の規約のため）
- 読み取りは prompt_id で groupBy し **max 集計**で最新版サマリを採用
  （last-wins 追記の読み側 — CONTRACT §3.4）
- フッタの合計 = 窓に重なった依頼の**全量**合計（窓内の寄与額ではない）
- 制約: 直近30秒ほどの依頼はサマリ未生成のことがある（テイラーのラグ）。
  入力のみで API 呼び出しが1件も無い依頼（即中断等・コスト0）はサマリが
  作られないため載らない

### 活用
- Today バーン推移のスパイク → バークリック → ここで犯人特定 →
  prompt_id クリックで Prompt明細（トークン内訳・経路・ツール）へ
- 「窓へいくら寄与したか」ではなく「この時間帯に走っていた依頼の素性」を見る場所
  （寄与額の合計は Today のバーの高さが正）
- 時間ピッカーを動かすと検索対象範囲が変わるだけで窓は不変
  （窓を変えたいときは Today から別のバーをクリックする）
