# プロンプト一覧ページ要件

## 背景 — なぜこのページがあるのか

「この時間帯、何の依頼が走っていたか」に答える時間窓ドリルダウン。
Today のバーン推移でスパイクのバーをクリックすると、**その5分窓が from/to として
引き継がれて**このページに遷移する（Today 自体の時間範囲は変えない — 常時ページの
レンジ固定規律を守るための分離）。

## 設計思想

- **実行期間の重なり判定 × 全量表示**: `prompt_summary`（CONTRACT §3.4）を
  `end_ms >= 窓開始 ∧ start_ms <= 窓終端` でフィルタ。跨ぎ依頼も漏れず、
  値は**真の全体期間・総コスト**（窓で切られない）
- 窓はリンクの `var-wfrom / var-wto` で渡る。ページの時間レンジは検索対象範囲
  （窓終端の48h前〜窓終端）で、窓そのものではない
- 中断・放置された依頼も漏れない（テイラーは Stop hook 等の発火イベントに依存しない）
