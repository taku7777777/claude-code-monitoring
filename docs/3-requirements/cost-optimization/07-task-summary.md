# タスク（workspace）別サマリ / 前週比較

タスク間・先週との差を「難易度の差か、進め方の差か」に分解する場所（タスク=workspace 運用）。

## 1. コスト 前週比

### 表示
- 同じ長さの期間を7日前と比較したコスト増減率（offset 7d）
- データが7日分溜まるまで No data

### 活用
- 「先週の自分」比較の入口
- 増えていたら CPSO 前週比とセットで読む（増加が仕事量か効率かを見るため）

## 2. CPSO 前週比

### 表示
- CPSO（成果あたりコスト）の前週比増減率

### 活用
- コスト増でも CPSO 平坦なら仕事量増（健全）と切り分ける
- CPSO +30% 超で診断セクションへ

## 3. タスク（workspace）別サマリ（期間内）

### 表示
- タスク=workspace 単位のコスト / 実効トークン / 成果数 / CPSO / prompt数 / 委任率
- 成果数の定義は概況「2. プロンプト完遂数」と同じ減算方式（CONTRACT §3.2）
- 注意: この表の委任率列は agent:* ÷ コスト全体であり、委任率パネル
  （agent:* ÷ (agent:*+repl)）とは分母が異なる（背景コストを含む分だけ僅かに低く出る）

### 活用
- 同種タスク間の比較（CASEBOOK Case 4）
- 差が出たら委任率・探索コスト比・手戻り（rework）で
  「難易度の差か、進め方の差か」を切り分ける
- retention（90日）超えの長期比較は analyzer --archive の CSV で行う
