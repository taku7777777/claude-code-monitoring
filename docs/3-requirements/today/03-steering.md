# ステアリング

「ペースを変えるべきか」に答える。使いすぎ→絞る と 余り→使い切る の**両方向**を
対等に扱う（枠は余らせても返ってこない）。

## 1. 累計コスト

### 表示
- 本日 00:00 からの累積コスト（5分ビンの累積。クエリ step=5m 固定 —
  step がビン幅より細かいと重複窓の累積で値が数倍に化けるため）
- 過去同曜日3週の同時刻平均カーブを重畳（サンプルが無い期間は非表示）
- $150 の赤破線 = 日次上限
- x軸は現在時刻まで（終日 00-24時軸は他パネルの相対窓と両立しない Grafana 制約）
- 施策マーカー（intervention_marker）が縦線で重畳される

### 活用
- 日末着地の目算はこのカーブの目視外挿で行う（専用の着地予測 stat は置かない —
  確定判断）
- 上限線より明らかに下で夕方を迎えたら「余り」— 後回しの重い作業を今日中に消化する
- 傾きが急変した時刻を自分の行動と突合する（暴走 A1 の「いつから」の確認）

## 2. 週消化 vs 経過 ($600)【削除済み 2026-07-13】

### 表示
- 上バー: 週次予算の消化率 / 下バー: 週の経過率（月曜起点）
- 色閾値なし — 残り枠の自然減に静的閾値を張れない問題を「経過率との対比」で解く
- 試験導入中（有意義でなければ削除の判断待ち）

### 活用
- 消化バーが経過バーを大きく超えていたら使いすぎ（週後半を絞る）、
  下回っていれば余り気味（積極的に使う）
- 数値の消化管理は週次レビュー（Cost Opt バーンレート節）の管轄

## 3. 月消化 vs 経過 ($2,000)【削除済み 2026-07-13】

### 表示
- 上バー: 月次予算の消化率 / 下バー: 月の経過率（毎月1日起点）
- 経過率の月長は31日で近似（短い月は経過率が実際より最大1割低く出る）
- 色閾値なし。試験導入中

### 活用
- 定常の実効ガバナ（月$2,000）に対する立ち位置の確認
- 消化が経過を超えている月は、日次が緑の日でも重い作業の閾値を上げる

## 4. バーン遷移（3h）

### 表示
- 直近3時間のコストを5分ビンの増分で表示（棒グラフ・レンジ固定 — Today の
  時間範囲は変えない）
- **バーをクリック → 「この5分のプロンプト一覧」**で、その5分窓に実行が
  重なっていた依頼の一覧ページ（プロンプト一覧）へ遷移する
- 目安の破線 $1.25/5分 ≒ $15/h（A1 黄相当。縦軸のスケールによっては
  視認しづらい — 留意）
- 試験導入中（累積カーブの傾きと情報が重複するため、取捨の第一候補）

### 活用
- 「いつから燃えているか」を自分の行動と突合し、A1 黄赤時の
  「意図した実行か」の判断材料にする
- スパイクのバーをクリック → プロンプト一覧で犯人を特定 → prompt_id で明細へ
